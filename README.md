# 03 · logscope

Stream and analyse nginx/Apache access logs without loading them into memory.

## Run
```bash
python -m logscope --help
```

## Test
```bash
pytest projects/03-logscope -q
```

See the module docstrings for the design notes; every public function has a test.

## Repository
- GitHub: https://github.com/{owner}/logscope
- Python 3.11+ · tests: `pytest` · runtime dependencies: none (standard library only)
